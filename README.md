# CosplayNesia

Homepage marketplace sewa dan beli kostum cosplay yang terinspirasi dari pola pengalaman pengguna Cosulagi, dibangun sebagai implementasi mandiri dengan identitas CosplayNesia.

## Menjalankan Lokal

```powershell
npx --yes serve -l 4173
```

Buka `http://127.0.0.1:4173`.

## Fitur

- Katalog responsif untuk desktop dan mobile
- Pencarian produk dan filter kategori
- Pengurutan katalog dan load more
- Detail produk dalam modal
- Favorit dan keranjang dengan subtotal
- Drawer keranjang serta modal akun
- Navigasi mobile dan semantic HTML

Data produk masih berupa data demo di `app.js`. Integrasi autentikasi, inventori, checkout, dan payment gateway memerlukan backend.
